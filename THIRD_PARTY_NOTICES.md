# Third-party notices

## Smartisan OS UI Kit (Unofficial) — CC BY 4.0

`lib/smartisan/` vendors the Flutter port of the
[Smartisan OS UI Kit (Unofficial)](https://www.figma.com/community/file/1419385240874679870)
by **Paix Chan**, released under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The kit reproduces Smartisan OS 8 as shipped on a Smartisan R2; its dimensions
and motion values were measured on that device.

Local changes to the vendored copy (kept minimal so it can be re-synced):
`SAppBar` title ellipsis, `SPopupMenu` item ellipsis, and `unawaited(...)` on
four fire-and-forget haptics / animation futures.
